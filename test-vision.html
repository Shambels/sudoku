Sudoku vision harness

Runs vision.js over every labelled fixture and scores it. Empty-vs-digit is reported separately from digit identity, because an empty-detection error is unrecoverable downstream while a digit error is often repairable by the solver. "Wrong & flagged" is the one that decides whether the human-in-the-loop story works: a wrong cell the pipeline knew it was unsure about costs the user a glance; one it was confident about costs them a wrong solve.

The browser will not let this page read the fixture pixels. Opened over file://, Chrome treats every local image as a separate origin and taints the canvas. Two ways round it:
1. serve the folder — python3 -m http.server, then open http://localhost:8000/test-vision.html; or
2. pick the fixtures folder here, which hands the page real File objects:
